## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임명 | 라스트 서바이벌 (Last Survival) |
| 장르 | 협동 생존 + 기지 방어 (세션형 PvE) **[가정]** |
| 플랫폼 | Roblox (PC, 모바일, 콘솔, 태블릿) |
| 타깃 | 만 9~16세 중심 Roblox 이용자, 생존·제작·디펜스 장르 선호층 |
| 서버당 인원 | 1~8명 **[가정]** |
| 1판 길이 | 약 30~40분 |
| 한 줄 소개 | 감염체가 뒤덮은 섬에서 친구들과 7일 밤을 버티고, 마지막 구조 헬기에 올라타라. |

### 1.1 핵심 컨셉
- 낮에는 **탐색·채집·제작**, 밤에는 몰려오는 감염체를 **기지에서 방어**한다.
- 밤이 지날수록 적이 강해지고, 안전 지역은 줄어든다.
- 7일째 밤을 버티면 8일째 아침 **구조 헬기**가 오고, 탈출 지점에 도착한 사람만 "라스트 서바이버"가 된다.
- 한 판이 끝나면 획득한 **생존 포인트**로 다음 판에 쓸 직업·시작 장비를 해금한다.

### 1.2 차별점 (USP)
1. **명확한 끝이 있는 생존**: 무한 생존 대신 "7일 후 탈출"이라는 목표. 30~40분 안에 기승전결이 난다.
2. **낮/밤 리듬**: 준비(낮)와 긴장(밤)이 번갈아 와서 루프가 지루하지 않다.
3. **역할 분담 협동**: 직업마다 잘하는 일이 달라 4~8명이 자연스럽게 나눠 맡는다.
4. **마지막 탈출 연출**: 헬기 좌석 수 제한 같은 극적인 마무리 **[가정, 질문 Q1-4]**.

### 1.3 디자인 원칙
- **3분 안에 재미**: 튜토리얼 없이도 첫 낮에 나무 캐기 → 도구 제작 → 바리케이드 설치까지 갈 수 있어야 한다.
- **모바일 우선 조작**: 버튼 4개 이하로 핵심 행동이 끝나야 한다.
- **혼자도 가능, 같이하면 더 쉽게**: 솔로 클리어도 되게 하되 인원수에 따라 난이도를 조절한다.
- **결제는 편의·꾸미기 중심**: 판의 승패를 돈으로 결정하지 않는다.

## 2. 게임 루프

### 2.1 마이크로 루프 (수십 초)
```
이동/탐색 → 자원 발견 → 채집 → 인벤토리 획득 → (다음 자원)
```

### 2.2 매크로 루프 (하루 = 약 5분)
```
[낮 3분]  탐색·채집 → 제작 → 기지 건설·보강 → 보급품 이벤트
   ↓
[해질녘 15초] 경고 사이렌 → 기지로 복귀
   ↓
[밤 2분]  감염체 웨이브 방어 → 생존/사망 → 보상
   ↓
다음 날 (난이도 상승)
```

### 2.3 메타 루프 (판과 판 사이)
```
로비 → 직업·시작 장비 선택 → 매치 (7일) → 결과·보상 → 해금·성장 → 로비
```

## 3. 게임 흐름

| 단계 | 장소 | 내용 |
|---|---|---|
| 1. 로비 | 로비 플레이스 | 캐릭터 꾸미기, 직업 선택, 상점, 퀘스트 확인, 파티 구성 |
| 2. 매칭 | 로비 → 매치 서버 | 엘리베이터/버스 탑승 방식으로 인원 모집 후 TeleportService로 이동 |
| 3. 1일차 낮 | 매치 | 무작위 지점 낙하산 착지 또는 공통 스폰 **[가정]** |
| 4. 1~7일차 | 매치 | 낮/밤 반복, 3·5일차 밤에 보스급 적 등장 |
| 5. 탈출 | 매치 | 8일 아침 탈출 지점 공개, 헬기 도착까지 90초 방어 |
| 6. 결과 | 매치 → 로비 | 생존 일수·처치 수·기여도 표시, 보상 지급 후 로비 복귀 |

## 4. 핵심 시스템

### 4.1 생존 스탯

| 스탯 | 범위 | 감소 | 0일 때 | 회복 |
|---|---|---|---|---|
| 체력 (HP) | 0~100 | 피격, 굶주림 | 다운(쓰러짐) | 붕대, 음식, 휴식 |
| 배고픔 | 0~100 | 초당 0.15 (약 11분에 0) | 체력 초당 1 감소 | 음식 |
| 목마름 | 0~100 | 초당 0.2 (약 8분에 0) | 체력 초당 1 감소 | 물, 과일 |
| 스태미나 | 0~100 | 달리기, 근접 공격 | 달리기 불가 | 자동 회복 |

- 수치는 초기값이며 플레이테스트로 조정한다.
- 체온·질병 같은 추가 스탯은 MVP에서 뺀다 **[질문 Q4-1]**.

### 4.2 잡힘·다운·부활
- HP 0 → **다운 상태** 30초. 아군이 5초간 상호작용하면 HP 30으로 부활 **[가정, 질문 Q4-6]**.
- 30초 안에 부활하지 못하거나 다운 중 추가 피격을 받으면 **잡힘(탈락)**.
- **[확정] 잡힌 플레이어는 즉시 관전 모드로 전환되어 살아있는 다른 플레이어의 플레이를 본다** (4.2.1).
- 잡힌 플레이어를 게임에 다시 들여보낼 수 있는지는 미정 **[가정: 다음 날 아침 아군이 "구조 신호탄"을 쓰면 복귀, 질문 Q4-3]**.
- 모두 잡히면 매치 종료 → 결과 화면.

#### 4.2.1 관전 모드 [확정 요구사항]

| 항목 | 규칙 |
|---|---|
| 진입 | 잡힘 판정 → 2초간 잡힘 연출(화면 어두워짐 + "잡혔습니다") → 자동으로 관전 시작 |
| 첫 관전 대상 | 가장 가까이 있던 살아있는 아군 |
| 대상 바꾸기 | 이전/다음 버튼 (PC: Q/E 또는 ←/→, 모바일: 화면 버튼, 콘솔: LB/RB) |
| 카메라 | 대상 캐릭터를 따라가는 3인칭 시점. 마우스·터치로 대상 주변을 돌려볼 수 있음 |
| 대상이 잡히면 | 1초 후 다음 생존자로 자동 전환 |
| 관전자 캐릭터 | 맵에서 제거. 적·아이템·건축물과 상호작용할 수 없음 |
| 관전 화면 정보 | 대상 이름·HP, 일차·남은 시간, 남은 생존자 수 / 전체 인원 |
| 소통 | 채팅 가능. 지도에 핑 찍기는 **[질문 Q4-7]** |
| 나가기 | "로비로 돌아가기" 버튼. 잡힌 시점까지의 보상은 나가도 받음 |
| 끝까지 관전 보너스 | 팀이 탈출에 성공하면 끝까지 남아 관전한 사람에게 추가 SP **[가정]** |
| 부활 시 | 관전 종료 → 기지 근처에서 다시 등장 (Q4-3에서 부활을 허용할 경우) |

### 4.3 채집

| 자원 | 얻는 곳 | 도구 | 주 용도 |
|---|---|---|---|
| 나무 | 나무 | 맨손/도끼 | 바리케이드, 횃불, 기본 도구 |
| 돌 | 바위 | 맨손/곡괭이 | 벽, 도구 강화 |
| 고철 | 폐차, 폐건물 | 렌치 | 무기, 함정 |
| 천 | 폐가 상자 | 없음 | 붕대, 가방 |
| 음식 | 덤불, 사냥, 보급품 | 없음 | 배고픔 회복 |
| 물 | 우물, 강, 빗물 통 | 물병 | 목마름 회복 |
| 부품 | 보급품, 보스 | 없음 | 상위 제작, 발전기 |

- 자원 노드는 일정 시간 뒤 다시 생긴다 (나무 90초, 바위 120초 등).
- 상호작용은 **ProximityPrompt** 기반으로 해서 모바일 조작을 단순하게 한다.

### 4.4 제작
- 인벤토리 화면에서 레시피를 고르면 즉시 또는 짧은 시간(1~3초) 후 완성.
- **작업대**를 기지에 설치하면 2단계 레시피가 열리고, **발전기**를 고치면 3단계가 열린다.

| 단계 | 조건 | 예시 |
|---|---|---|
| 1단계 | 없음 | 돌도끼, 돌곡괭이, 횃불, 나무 바리케이드, 붕대 |
| 2단계 | 작업대 | 쇠도끼, 활, 나무 벽, 가시 함정, 물병 |
| 3단계 | 발전기 | 석궁, 산탄 장치, 철벽, 자동 포탑, 서치라이트 |

### 4.5 기지 건설
- 맵 곳곳의 **거점 후보지**(폐주유소, 농가, 등대 등) 중 팀이 하나를 골라 깃발을 꽂으면 기지가 된다 **[가정, 질문 Q5-3]**.
- 기지 반경 안에서만 건설 가능. 그리드 스냅 (4 스터드) 배치.
- 건축물에는 내구도가 있고, 망치로 수리한다.
- 서버 부하를 고려해 서버당 건축물 수 상한을 둔다 (예: 150개).

### 4.6 전투
- **근접**: 도구·근접 무기 (클릭/탭 공격, 스태미나 소모)
- **원거리**: 활·석궁·투척물 (조준은 화면 중앙 또는 자동 조준 보조)
- **설치형**: 함정, 포탑
- 피격 판정은 **서버가 최종 판단**한다 (클라이언트는 연출만).
- 아군 사격은 기본 비활성 **[질문 Q2-2]**.

### 4.7 적 (감염체)

| 적 | 등장 | 특징 |
|---|---|---|
| 배회자 | 1일차~ | 느림, 낮에도 소수 배회 |
| 달리미 | 2일차~ | 빠름, 체력 낮음 |
| 덩치 | 3일차~ | 느림, 건축물에 큰 피해 |
| 비명꾼 | 4일차~ | 주변 감염체를 불러모음 |
| 독침꾼 | 5일차~ | 원거리 공격 |
| 우두머리 (보스) | 3·5·7일차 밤 | 일차마다 다른 패턴, 처치 시 부품 대량 |

- **웨이브 규칙**: 밤마다 정해진 수의 적이 기지 방향으로 몰려온다.
  적 수 = `기본값(일차) × 인원 보정(1인 0.6 ~ 8인 1.8)`
- **AI**: PathfindingService로 기지까지 경로를 찾고, 막히면 가장 가까운 건축물을 공격한다.
- **성능**: 동시 활성 적 상한 60마리 **[가정]**, 멀리 있는 적은 단순 이동으로 처리.
- **표현 수위**: 피·신체 훼손 없이 연기·빛으로 처리 (Roblox 연령 등급 고려, 질문 Q11-1).

### 4.8 낮/밤과 이벤트

| 시간 | 길이 | 내용 |
|---|---|---|
| 낮 | 3분 | 채집·제작, 소수 배회자 |
| 해질녘 | 15초 | 사이렌, 하늘 색 변화, 남은 시간 표시 |
| 밤 | 2분 | 웨이브, 시야 감소, 횃불·서치라이트 중요 |
| 새벽 | 5초 | 남은 적 퇴각, 생존 보상 |

**낮 이벤트 (무작위 1개/일)**
- 보급품 투하: 지도에 표시, 먼저 도착한 팀원이 획득
- 생존자 무전: 특정 장소에 숨겨진 상자
- 산성비: 실외에 있으면 HP 감소, 빗물 통에 물이 찬다

### 4.9 맵
- **섬 1개**, 약 1,000 × 1,000 스터드 **[가정, 질문 Q3-1]**
- 구역: 해변(시작) → 숲 → 마을 → 공장지대 → 군사기지(탈출 지점 후보)
- 바깥 구역일수록 좋은 자원과 강한 적
- 5일차부터 **오염 구역**이 바깥에서부터 좁혀진다 (안에 있으면 지속 피해)
- StreamingEnabled 사용으로 모바일 메모리 부담을 줄인다

### 4.10 탈출 (엔딩)
- 8일차 아침, 탈출 지점 1곳 공개 (매 판 무작위 3곳 중 1곳)
- 헬기 도착까지 90초 동안 마지막 웨이브 방어
- 헬기 탑승 성공 = **탈출 성공**, 최대 보상
- 탈출 실패라도 버틴 일수만큼 보상 지급

## 5. 진행·성장 (메타)

### 5.1 생존 포인트 (SP)
- 판마다 생존 일수, 처치 수, 제작·건설·부활 기여에 따라 지급
- 사용처: 직업 해금, 직업 레벨업, 시작 장비 슬롯

### 5.2 직업

| 직업 | 해금 | 특성 |
|---|---|---|
| 생존자 | 기본 | 균형형 |
| 나무꾼 | 기본 | 채집 속도 +30% |
| 기술자 | SP | 건축물 내구도 +25%, 수리 속도 +50% |
| 의무병 | SP | 부활 시간 -50%, 붕대 효과 +50% |
| 사냥꾼 | SP | 원거리 피해 +20%, 이동 속도 +10% |
| 정찰병 | SP | 보급품 위치 먼저 확인, 스태미나 +30% |

- 직업 특성은 **편의·역할** 위주로, 판 밖의 결제로 사지 않는다 **[질문 Q8-2]**.

### 5.3 기타 진행 요소
- 플레이어 레벨 (경험치 → 칭호, 꾸미기 보상)
- 일일·주간 퀘스트
- 업적 및 Roblox 배지 (첫 탈출, 솔로 탈출, 7일 무사망 등)
- 시즌 랭킹 (최단 탈출 시간) **[질문 Q8-4]**

## 6. 수익 모델 (Robux)

| 종류 | 상품 예시 | 원칙 |
|---|---|---|
| 게임패스 | VIP (로비 전용 이모트, 이름 색상), 추가 인벤토리 칸 | 영구 편의 |

| 꾸미기 | 캐릭터 스킨, 무기 스킨, 기지 깃발 | 능력치 변화 없음 |
| 프리미엄 페이아웃 | Roblox Premium 유저 체류 시간 | 자동 |
| 비공개 서버 | 친구끼리만 하는 서버 | 유료 또는 무료 선택 |

- 결제 처리는 `MarketplaceService.ProcessReceipt`에서 **중복 지급 방지** 기록을 남기고 처리한다.

## 8. 아트·사운드 방향
- **아트**: 밝은 낮과 어두운 밤의 대비가 큰 로우폴리 스타일. 감염체는 녹색 발광 + 실루엣 위주로, 무섭지만 잔인하지 않게.
- **조명**: Future 조명, 밤에는 횃불·서치라이트가 주요 광원.
- **사운드**: 낮에는 잔잔한 환경음, 해질녘 사이렌, 밤에는 긴장감 있는 BGM, 보스 등장 전용 음악.

## 9. 기술 구조 (초안)

### 9.1 플레이스 구성
- **로비 플레이스**: 꾸미기, 상점, 매칭
- **매치 플레이스**: 실제 게임 (서버당 최대 8명)
- TeleportService로 파티 단위 이동, 이동 시 선택 직업 등은 TeleportData가 아닌 서버 측 데이터로 확인

### 9.2 코드 구조 (제안)
```
src/
  ReplicatedStorage/
    Shared/        -- 아이템·레시피·적 데이터 테이블, 공용 유틸
    Remotes/       -- RemoteEvent/RemoteFunction 정의
  ServerScriptService/
    Services/      -- DayNightService, WaveService, EnemyService,
                   -- InventoryService, CraftingService, BuildingService,
                   -- DataService, MatchService, ShopService,
                   -- SpectateService
  StarterPlayer/
    StarterPlayerScripts/
      Controllers/ -- InputController, UIController, BuildController,
                   -- CameraController, SoundController, SpectateController
```

**관전 모드 구현 메모**
- 서버(`SpectateService`)가 잡힘 상태와 관전 대상을 관리하고, 플레이어 Attribute(`State = "Spectating"`, `SpectateTarget`)로 클라이언트에 알린다.
- 클라이언트(`SpectateController`)는 `Camera.CameraSubject`를 대상의 Humanoid로 바꾸고 관전 UI를 띄운다.
- StreamingEnabled 환경에서는 관전자 근처가 아니라 대상 근처 맵이 보여야 하므로, 서버에서 관전자의 `Player.ReplicationFocus`를 대상의 HumanoidRootPart로 바꾼다.
- 관전자의 원격 호출(채집·공격·건설 등)은 서버에서 모두 거절한다.
- 서버 권한 구조: 아이템 획득·제작·피해·건설은 모두 서버에서 검증
- 데이터 정의는 Luau 테이블(ModuleScript)로 분리해서 기획자가 수치만 고칠 수 있게 함

### 9.3 데이터 저장
- DataStoreService (세션 잠금 처리, 자동 저장, 종료 시 저장)
- 저장 항목: SP, 해금 직업, 직업 레벨, 꾸미기 소유, 퀘스트 진행, 통계
- 매치 중 인벤토리·기지는 **저장하지 않음** (판이 끝나면 초기화)

### 9.4 성능 목표
- 모바일 30 FPS 이상, 서버 하트비트 55 이상 (8명 + 적 60마리 + 건축물 150개 기준)
- StreamingEnabled, 적 AI 업데이트 주기 분산, 건축물 파트 수 최소화
