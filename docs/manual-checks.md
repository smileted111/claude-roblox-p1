# 수동 확인 목록

Claude가 혼자 확인할 수 없는 작업(여러 명이 접속하는 테스트, 실제 기기, 게시된 게임, Creator Hub 설정, 재미 판단)을 단계별로 모은다.
확인하면 `- [ ]`를 `- [x]`로 바꾸고, 문제가 있으면 줄 끝에 증상을 적어 Claude에게 알려준다.

**여러 명 테스트 방법**: Studio **테스트 (Test)** 탭 → **클라이언트 및 서버 (Clients and Servers)** 에서 플레이어 수를 고르고 **시작 (Start)**.
**휴대폰 화면 확인**: **테스트 (Test)** → **기기 (Device)** 에서 휴대폰 기종을 고른다.

**실제 휴대폰으로 게시된 게임 접속** (게임이 비공개라 앱 검색·홈에는 나오지 않는다. 휴대폰·태블릿 허용은 켜져 있음):
1. Studio에서 **파일 (File) → Roblox에 게시 (Publish to Roblox)**. 휴대폰은 마지막으로 게시한 버전을 받는다 (저장만 한 버전은 아님).
2. 휴대폰 브라우저에서 `https://www.roblox.com/games/131560237546176` 를 열고 **플레이** → Roblox 앱이 열린다. Roblox 채팅으로 링크를 보내도 된다.
3. 휴대폰에 로그인한 계정에 따라:
   - **본인(소유자) 계정**: 추가 설정 없이 바로 들어간다.
   - **다른 계정 → 얼리 테스터**: Studio **File → Invite early testers** (또는 게시 창의 **Invite**). Roblox 친구만, 최대 10명. 나이 범위: 본인이 18세 이상이면 16세 이상 친구만 (그 밖은 "신뢰하는 친구(trusted friends)"여야 함). 초대할 때 본인 나이 확인(age check)을 요구하면 끝까지 해야 초대가 간다. 초대한 사람은 Studio 오른쪽 위 **Manage Collaborators** 에 초대 날짜와 함께 보인다. 들어가면 "미리 보기" 워터마크가 보이는 게 정상.
   - **친구가 아닌 계정 → 플레이 권한**: Studio **Collaborate** 에서 Play 권한을 주고, Creator Hub → 게임 → **Publish settings → Manage Audience → Manage access → Playtest** 탭에서 **Playtesters** 를 켜고 **Save Changes**.
4. 링크만 있으면 누구나 들어오는 설정은 없다. 비공개 게임은 위 목록에 있는 계정만 들어온다.

  7. 일반 서버에서 초록 발판에 혼자 30초 → 창에서 [혼자 하기] → 3과 같이 이동한다.

## S3-4 괴물 그림자·거인

- [ ] Studio에서 **저장(Ctrl+S)**: `ServerStorage.MonsterModels`에 그림자(Shadow)·거인(Giant) 임시 외형이 새로 생겼다.
- [ ] Stage3 어두운 구역(DarkZone)에서 그림자가 **화면으로 봤을 때** 거의 안 보이고, 밝은 곳에 나오면 다시 보인다 (투명도 값은 확인했지만 실제 조명 아래 보이는 정도는 사람 눈으로).
- [ ] 손전등: 켜면 앞쪽이 밝아지고, HUD 칸에 "손전등 n%"가 줄어든다. 배터리 30초가 적당한지. 그림자를 비추면 멈추는 것이 화면에서도 자연스러운지.
- [ ] 알람시계: 카메라로 보는 곳에 던져지고(최대 40스터드) 노란 시계가 5초 동안 보인다. **알람 소리 효과음은 아직 없다** (사운드 에셋을 정하면 SoundController에 연결).
- [ ] 거인: 크기(키 약 8.8)가 문·복도를 지나가기에 맞는지, 판자·문을 부수는 모습이 이상하지 않은지 (지금은 그냥 사라짐). 부서진 숨는 곳은 어두운 색이 된다.
- [ ] 3명 이상: 추격자와 거인이 같이 있을 때, 거인에게 잡힌 생존자가 관전으로 넘어가고 결과 화면 "잡힘"이 맞게 나온다.
- [ ] 아이템 출현 비율(손전등·알람시계 SpawnWeight 2, 붕대 3·연막탄 2·에너지 드링크 3)이 적당한지.

## S3-5 모바일·콘솔 조작

Studio에서는 실제 터치 입력을 낼 수 없어 마우스로 화면 버튼을 눌러 시험했다. 아래는 실제 기기로 확인한다
(게시 후 휴대폰 접속 방법은 이 파일 맨 위).

- [ ] 휴대폰: 오른쪽 아래 점프 버튼 둘레에 생존자는 [달리기]·[아이템]·[상호작용](프롬프트 근처에서만), 추격자는 [스킬]이 보이고 **엄지로 편하게 닿는지**, Roblox 점프 버튼·이동 스틱과 겹치지 않는지. 위치는 `Config/Input.luau`의 `Touch.Offsets`.
- [ ] 휴대폰: [달리기]를 누른 채 이동 스틱으로 움직이면 달리고, 손가락을 버튼 밖으로 밀어도 떼면 멈춘다.
- [ ] 휴대폰: [상호작용]으로 숨기·나오기·수리(누르고 있기)·치료·줍기·판자·문·열어보기가 된다. Roblox 기본 프롬프트를 직접 탭해도 된다.
- [ ] 휴대폰: 추격자 공격이 화면 탭으로 되고, 카메라를 돌리려고 끌 때는 공격되지 않는다. **결정 필요**: GDD 11장대로 화면 버튼은 4개(달리기·상호작용·아이템·스킬)라 공격 버튼은 없다. 탭 공격이 불편하면 추격자용 [공격] 버튼을 달리기 자리에 추가할 수 있다.
- [ ] 태블릿(짧은 변 500점 초과): 버튼이 1.5배로 커지고 큰 점프 버튼과 겹치지 않는다.
- [ ] 휴대폰: HUD·로비·관전·결과 화면 글씨가 읽히고 버튼(56 × 0.8 = 약 45점)이 누르기 쉬운지.
- [ ] 게임패드: L3 달리기, R2 공격, LB/RB 아이템, Y 스킬, X 상호작용, 관전 중 LB/RB 대상 바꾸기. 화면 키 안내가 [L3]·[LB]·[R2]·[Y]로 바뀐다. 로비 버튼은 Roblox 기본 UI 선택(게임패드 Select/\\ 키)으로 누른다.
- [ ] Xbox·PlayStation 버튼 이름: 안내는 GDD 표기(L3·R2·LB·RB·Y·X)를 쓴다. PlayStation에서 어색하면 `Config/Input.luau`의 `KeyNames`를 바꾼다.

## S3-6 상점·게임패스

- [ ] **사용자 입력 필요**: Creator Hub → 이 게임 → **수익화 (Monetization)** 에서 게임패스 `VIP`와 개발자 상품 `코인 묶음` 3개를 만들고, ID를 `src/shared/Config/Shop.luau`의 `VipPassId`와 `CoinProducts[n].ProductId`에 넣는다 (가격은 질문지 Q7-5대로 출시 직전 결정). 코인 수(100·550·1200)도 임시값이다. 그 뒤 Claude에게 확인을 요청하면 된다.
- [ ] **Studio에서 테스트 구매** (ID를 넣은 뒤, 게임을 게시한 상태):
  1. Studio **홈 → 게임 설정 → 보안**에서 **Studio의 API 서비스 접근 허용**이 켜져 있는지 본다 (데이터 저장용, 이미 켜져 있음).
  2. 플레이 → 로비 왼쪽 위 [상점] → 코인 묶음 버튼을 누르면 "테스트 구매입니다(결제되지 않음)" 창이 뜬다 → 구매.
  3. 출력 창에 `[Shop] ... 코인 묶음 <ID>: 코인 +N` 이 찍히고, 로비 코인이 늘고 "코인 N개를 받았습니다!" 알림이 뜬다 (저장 확인 때문에 Roblox 구매 완료 표시가 최대 수십 초 늦을 수 있다).
  4. 플레이를 멈췄다 다시 시작해 코인이 그대로인지 본다.
  5. VIP 버튼 → 테스트 구매 → "VIP가 되었습니다!" 알림, 상점 "보유 중", 로비 [이모트] 버튼. Studio 테스트 구매는 실제 보유가 아니라서 다시 플레이하면 VIP가 아니다 (정상).
- [ ] 게시된 게임(실제 결제, 소량)으로 한 번: 코인 묶음 구매 → 나갔다 다시 들어와도 코인 유지, VIP 구매 → 다시 들어와도 VIP.
- [ ] VIP 채팅: 채팅 창에서 VIP 이름 앞에 노란 `[VIP]`가 붙는지, 관전 중 채팅은 `[관전] [VIP] 이름` 으로 보이는지 (채팅 창은 스크린샷에 안 잡혀 확인하지 못함).
- [ ] VIP 로비 이모트: 임시로 Roblox 기본 춤(`Config/Assets.luau` `VipEmote`)이다. 전용 이모트 애니메이션을 정하면 ID를 바꾼다.
- [ ] 로비 패널(왼쪽 위)이 Roblox 채팅 창과 겹쳐 보이는지 (S3-2부터 같은 자리). 겹치면 패널 위치를 정해 알려준다.
- [ ] VIP 코인 +20%는 스테이지·칭호로 **버는** 코인에만 붙고 산 코인에는 붙지 않게 했다. 산 코인에도 붙이고 싶으면 알려준다.

## S3-7 한국어·영어 현지화

- [ ] **Studio에서 영어 화면 보기 (공식 방법)**: **테스트 (Test)** 탭 → **플레이어 에뮬레이터 (Player Emulator)** → **에뮬레이션 사용** 켜기 → **로캘 (Locale)** 을 `English (en-us)`로 고르고 플레이 → 로비·HUD·프롬프트·결과가 영어로 나오는지 확인 (Claude는 아래 개발용 속성으로만 시험했다). 한국어로 되돌리려면 로캘을 `한국어 (ko-kr)`로 (에뮬레이터를 끄면 Roblox 계정 언어를 따른다).
  - 빠른 방법(개발용): 편집 모드에서 `ReplicatedStorage`에 문자열 속성 `StudioLanguage` = `en`을 추가하고 플레이. **시험 뒤 속성을 지우고 저장**한다 (Studio에서만 쓰이고 게시된 게임에는 영향 없음).
- [ ] 영어 번역 문장과 용어가 자연스러운지 (`src/shared/Localization/en.luau`). 특히 단계 이름(Get Ready·Chase), 스테이지 이름(Abandoned School 등), 추격자 스킬 이름(Dash·Track·Blink·Call Monsters), 프롬프트(Hide·Come Out·Search·Push Over).
- [ ] 영어에서 글자가 잘리거나 넘치는 곳이 없는지: 휴대폰 화면(버튼 안 "Coming soon"·"Choose Chaser: Puppeteer", 화면 버튼 "Smoke Bomb"·"Energy Drink"), 관전 화면, 역할 공개 카드.
- [ ] 영어 계정(또는 에뮬레이터)에서 Roblox 채팅의 관전자 접두사가 `[Spectator]`, VIP는 `[VIP]`로 보이는지.
- [ ] 한국어·영어가 아닌 언어(예: 일본어)로 들어오면 영어로 나온다 (의도). 다른 언어를 더하려면 `Localization/<언어>.luau`를 만들고 `Localization/init.luau`의 표·언어 목록에 더한다.

## S3-8 정식 맵

- [ ] **사용자 작업**: 블록 맵의 동선(벽·문·판자·숨는 곳·발전기 위치)을 유지하면서 건물·소품을 꾸민다 (에셋 수급은 질문지 Q11-1 — 아직 답변 필요). 꾸민 뒤 Studio에서 **저장(Ctrl+S)** 하고 Claude에게 "맵 점검"을 요청하면 `tools/mapcheck/audit.luau`로 다시 점검한다.
- [ ] **승인 필요 (낮음)**: 지금 블록 맵은 발전기·출구 근처에 조명이 없는 곳이 있다 (Stage1은 조명 0개로 주변광만, Stage2 발전기 1·3과 출구 2곳, Stage3 출구 2곳). 꾸밀 때 비상등을 두면 해결된다. Claude가 지금 블록 맵에 임시 조명(PointLight, 그림자 끔)을 달기를 원하면 알려준다.
