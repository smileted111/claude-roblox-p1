# 수동 확인 목록

Claude가 혼자 확인할 수 없는 작업(여러 명이 접속하는 테스트, 실제 기기, 게시된 게임, Creator Hub 설정, 재미 판단)을 단계별로 모은다.
확인하면 `- [ ]`를 `- [x]`로 바꾸고, 문제가 있으면 줄 끝에 증상을 적어 Claude에게 알려준다.

**여러 명 테스트 방법**: Studio **테스트 (Test)** 탭 → **클라이언트 및 서버 (Clients and Servers)** 에서 플레이어 수를 고르고 **시작 (Start)**.
**휴대폰 화면 확인**: **테스트 (Test)** → **기기 (Device)** 에서 휴대폰 기종을 고른다.

## 이전 단계에서 남은 항목 (S1-3 ~ S1-7)

`docs/progress.md`에 "사용자 확인 대기"로 적힌 것들이다.

- [ ] S1-3 3명: 1명은 추격자 대기실에서 시작하고, 15초 뒤 대기실 문이 열린다.
- [ ] S1-4 3명: 추격자가 옷장을 열어보면(1초 누르기) 숨은 생존자가 밖으로 나온다. 20초 넘게 숨은 옷장에 추격자가 12스터드 안으로 오면 빨갛게 강조된다.
- [ ] S1-5 3명: 추격자가 2번 때리면 생존자가 사라지고(암전 2초), 1번 맞은 생존자를 다른 생존자가 4초 눌러 치료할 수 있다.
- [ ] S1-7 3명: 잡힌 사람 화면이 다른 사람을 따라가고 Q/E(←/→)로 대상이 바뀐다. 대상이 잡히면 1초 뒤 다음 대상으로 넘어간다. 관전자가 쓴 채팅이 생존자 화면에 보이지 않는다.

## S1-8 기본 HUD

- [ ] **테스트 (Test) → 기기 (Device)** 에서 휴대폰(예: iPhone 14, 가로)으로 바꿔 플레이: 위 시간 패널, 아래 생존자 HUD(상태·스태미나·아이템 2칸)가 이동 스틱·점프·달리기 버튼과 겹치지 않는다. (Claude는 같은 크기 틀에 HUD를 넣어 확인함)
- [ ] 3명: 스테이지 시작 때 룰렛이 후보 이름을 돌다가 추격자 이름에서 멈추고, 각자 화면에 "당신은 생존자입니다!" / "당신이 추격자입니다!"와 목표 한 줄이 나온다.
- [ ] 3명: 추격자가 클릭하면 아래 공격 바가 1.5초 동안 다시 차오르고 "공격 가능"으로 돌아온다.
- [ ] 글자 크기·색이 읽기 편한지 (특히 휴대폰에서 스테이지 이름·남은 생존자 줄).
