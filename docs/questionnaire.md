# 라스트 서바이벌 — 구현 전 확인 질문지 (v2)

장르가 **비대칭 추격 생존**으로 바뀌어 질문지를 새로 만들었다. `docs/GDD.md` v1.0과 짝을 이룬다.

**작성 방법**
- `답변` 칸은 Claude의 추천 답변으로 미리 채워 두었다. 바꾸고 싶은 칸만 고쳐 적는다.
- ✅ 추천 답변으로 진행 / ❓ 직접 답변 필요 / ⏸ 나중에 결정
- 우선순위: 🔴 프로토타입(M0) 전에 필요 / 🟡 MVP(M2) 전까지 필요 / 🟢 나중에 정해도 됨

## 확정된 답변

| 질문 | 답변 |
|---|---|
| 잡히면? | 다른 플레이어를 보는 관전 모드로 전환 |
| "잡힘"의 의미 | 추격자 역할의 플레이어에게 잡힘. 스테이지마다 괴물의 종류와 수가 다름 |
| 혼자 플레이 | 괴물만 등장 (추격자 없음) |
| 기존 Roblox 그룹·게임 | 없음 → 새로 만든다 |
